# PHASE 9 — AI FAILURE FALLBACK

This is mandatory.

If:

* AI API key is missing
* API fails
* request times out
* provider returns invalid data
* network fails

the report workflow must continue using mock AI.

Create:

`MOCK_AI_MODE=true`

When enabled:

→ use mock AI.

When disabled:

→ attempt real AI.

If real AI fails:

→ gracefully fall back to mock AI.

Show the user an appropriate message such as:

**AI analysis temporarily unavailable. You can continue with assisted classification.**
